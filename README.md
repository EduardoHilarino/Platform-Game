 [Platform Game]

A fast-paced 2D platformer focused on movement, precision, and experimentation, inspired by games like *Celeste*.

This project was developed using **GameMaker Studio 2**, with an emphasis on responsive controls, smooth movement mechanics, and a simple but polished gameplay experience.

## 🎮 About the Game

The goal is simple: **reach the end of the level!**

The game features a minimalistic level designed to give players the freedom to explore and experiment with its movement mechanics.

Rather than focusing on complex level design, this project emphasizes the feeling of movement and the satisfaction of mastering the controls.

## ✨ Features

- **Smooth Movement:** Responsive acceleration, deceleration, and directional control.
- **Jump Mechanics:** Coyote time and jump buffering for more forgiving platforming.
- **8-Directional Dash:** Dash in multiple directions to navigate the environment.
- **Checkpoints & Respawning:** Quickly return to the action after dying.
- **Visual Effects:** Custom shaders, lighting adjustments, dash trails, and blur effects.
- **Sound Design:** Sound effects for jumping, dashing, dying, respawning, and completing the game.
- **Audio Polish:** Echo effects and pitch variation to make sounds feel more dynamic.
- **Minimalist Art Style:** A simple visual environment that keeps the focus on gameplay.

## 🛠️ Made With

- **GameMaker Studio 2**: Game engine and programming.
- **GML (GameMaker Language)**: Gameplay systems and mechanics.
- **GLSL ES**: Custom shaders and visual effects.

## 🎯 Project Goals

This project was created to practice and improve my skills in game development, especially:

- Creating responsive and satisfying movement mechanics.
- Working with state machines and player physics.
- Implementing shaders and visual feedback.
- Designing and integrating sound effects.
- Polishing a playable game from start to finish.

## 🗺️ Level Design

The level is intentionally simple.

Instead of restricting the player to a complicated path, the environment provides enough freedom to test different movements, experiment with dashing, and become familiar with the controls.

The main focus is on **movement, experimentation, and gameplay feel**.

## 🔊 Audio & Visual Polish

- Sound effects for important gameplay events.
- Echo and pitch variation.
- Additional visual and audio feedback.

These improvements help make the game feel more responsive and polished.
